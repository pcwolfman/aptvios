# aptvios

APTV IPA analizi + **Aptvios 1.2** (özellik paritesi hedefli IPTV uygulaması).

| Klasör | Açıklama |
|--------|----------|
| `Aptvios/` | Xcode projesi — M3U/Xtream/Stalker, EPG, KSPlayer, CarPlay… |
| `extracted/` | APTV.ipa açılmış içerik |
| `ARCHITECTURE.md` | APTV mimari notları |

```bash
open Aptvios/Aptvios.xcodeproj
```
